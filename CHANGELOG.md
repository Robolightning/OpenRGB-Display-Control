# Changelog

## 0.1.0a1 — 2026-11-18 — experimental pre-release

* Extract the companion into an installable standalone package and optional Qt GUI.
* Keep native Matrix support in a separate, core-only OpenRGB patch.
* Fail explicitly on SDK errors; raw USB requires explicit selection.
* Preserve source animation speed under FPS limits and long stalls.
* Share encoding and preview, including EXIF, APNG posters, alpha and stepped holes.
* Fit text without Windows-specific fonts; portrait clock uses two lines.
* Add cancellable workers, serialized replacements and cross-platform writer locks.
* Document hardware scope, protocol provenance and unverified behavior.
